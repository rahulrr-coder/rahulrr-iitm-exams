W1

Data types & scales

0/3 learned · 21 marks
Scales
Nominal labels, no order · Ordinal ranked, gaps unequal · Interval equal gaps, NO true zero (ratios meaningless, 40°C ≠ 2×20°C) · Ratio equal gaps AND true zero (ratios valid)
Descriptive vs inferential
Summarises data collected → descriptive. Uses a sample to generalise to a population → inferential. Trigger words: generalise, population, sampling error, test a claim
× W1-A1 Scale-of-measurement property checklist
9 marks4 Q

For any statement about a scale type, run the checklist: nominal = labels/categories only (no order); ordinal = ranked but gaps unequal/unmeasurable; interval = equal gaps but NO true zero, so ratios are meaningless (e.g. 40°C is not 'twice' 20°C); ratio = equal gaps AND a true zero, so ratios ARE meaningful (e.g. income, weight, age) — the presence/absence of a genuine zero point is what separates interval from ratio.

× W1-A3 Cross-sectional vs time-series vs data-type classification
8 marks4 Q

First classify the collection structure: same variable(s) tracked over multiple time periods = time-series; different units/subjects observed at a single point in time = cross-sectional. Then classify each variable separately as qualitative (categorical, e.g. nominal/ordinal labels) or quantitative (numeric), and as structured (tabular/numeric) or unstructured (text, images, free-form) when that distinction is tested.

× W1-A2 Descriptive vs inferential statistics scope
4 marks2 Q

Ask of each statement: does it merely summarize/organize the data actually collected (mean, chart, table -> descriptive), or does it use a sample to draw a conclusion, estimate, or generalization about a larger population, typically invoking probability or hypothesis testing (-> inferential)? Statements that mention 'generalizing', 'population', 'sampling error', or 'testing a claim' are inferential; statements that just 'present' or 'summarize' data are descriptive.

W2

Charts & frequency

0/4 learned · 11 marks
Pie chart
amount = (percent/100) × total
Relative frequency
rel freq = class freq / Σ freq
× W2-A2 Convert pie chart percentages to actual amounts
5 marks2 Q

Multiply each category's stated percentage by the known total (or back out the total from one category's percent-and-value pair), then add or subtract the resulting amounts as the question asks.

× W2-A1 True/false statements on categorical variable properties
2 marks1 Q

Classify the variable as nominal or ordinal, then recall that mode is a valid summary for categorical data while covariance/correlation require numeric (interval/ratio) variables — check each statement against these definitions rather than computing anything.

× W2-A3 Evaluate statements from a pie chart of percentages
2 marks1 Q

Work directly with the percentage shares shown (no total needed) — rank categories by their percent slice or sum two slices to check a claimed comparison, then judge each statement true/false.

× W2-A4 Compute relative frequency from a bar chart
2 marks1 Q

Read off the bar height (frequency) for the category asked about, sum all bar heights to get the total, and divide: relative frequency = category frequency / total frequency.

W3

Central tendency & dispersion

0/4 learned · 41 marks
Mean
x̄ = Σx / n, so Σx = n·x̄ (use to back out a missing value)
Combined mean
x̄ = (n₁x̄₁ + n₂x̄₂)/(n₁+n₂) — weight by size, never average the averages
Quartiles / IQR
order data, locate Q₁ Q₃ by position, IQR = Q₃ − Q₁
Linear transform y = ax+b
mean → a·mean+b · median → a·median+b · percentile → a·p+b · Var → a²·Var · SD → |a|·SD · IQR → |a|·IQR. Location takes b, spread ignores b.
× W3-A4 Effect of a linear transform (y = a*x + b) on mean, median, percentile, variance, IQR
18 marks6 Q

For y = a*x + b: mean_y = a*mean_x + b and var_y = a^2*var_x; any single-point location statistic (median, a percentile) transforms the same way as the mean (multiply by a, add b); spread measures based on differences of two points (like IQR) are unaffected by a pure shift (b) and scale by |a| under a scale change.

× W3-A2 Combined/weighted mean of merged subgroups
10 marks3 Q

Use Sum(x) = n * mean for the whole group and for each subgroup; since the whole group's total sum equals the sum of subgroup totals, solve the resulting linear equation for the missing subgroup total or single observation.

× W3-A3 Solve for unknown(s) from a given mean, then derive another statistic
10 marks3 Q

Set up Sum(x) = n * mean as an equation in the unknown(s) (an unknown data value, a misrecorded entry, or an unknown variance term), solve algebraically, then plug back to compute the requested derived quantity (corrected mean, median, or |difference of unknowns|).

× W3-A1 IQR via ordered data and quartile position formula
3 marks1 Q

Sort the data, locate Q1 and Q3 using the quartile position formula (e.g. (n+1)/4 and 3(n+1)/4), then IQR = Q3 - Q1.

W4

Correlation

0/3 learned · 17 marks
Pearson r
r = [nΣxy − ΣxΣy] / √([nΣx² − (Σx)²][nΣy² − (Σy)²]) — build the 5 columns x, y, xy, x², y²
Invariance
r unchanged by positive linear transforms; a negative multiplier flips the sign only
Contingency table
row totals, column totals, grand total — then decide if the question wants joint, marginal or conditional
× W4-A1 Compute Pearson r from raw paired data
11 marks3 Q

Given paired (x,y) observations, compute r = [nΣxy - ΣxΣy] / sqrt([nΣx²-(Σx)²][nΣy²-(Σy)²]) (or use deviations from means) and read the sign/magnitude to judge strength and direction of the linear relationship.

× W4-A2 Correlation invariance under linear transformation
3 marks1 Q

If X and Y are each replaced by linear transforms a+bX and c+dY, correlation is unchanged in magnitude and its sign flips only if exactly one of b,d is negative — no recomputation needed, just track sign(b)*sign(d).

× W4-A3 Read and reason from a contingency table
3 marks2 Q

Locate the row/column intersection for the stated categories, use row/column/grand totals to back out any unknown cell via subtraction, then form the requested proportion (part/relevant total).

W1

Intro to algorithms

0/1 learned · 17 marks
Operators
/ always gives float · // floors · % remainder (days = n // 7, rest = n % 7) · ** power · int op float → float
Types
int float str bool · a quoted number is str · int('5')+1 = 6, '5'+1 is a TypeError · str + str joins, str * int repeats
Output formats
len(s) counts characters · f-string width f'{x:5}' right-aligns numbers in 5 columns · print(a, b) puts a space between
× W1-A1 Expression type and operator tracing
17 marks8 Q

Any "what type / what value / what output" on straight-line code: work inside-out. int op int is int except / (float) and ** with a negative power; int op float is float; a quoted literal is str even if it looks like a number; // floors, % keeps the remainder (days = n // 7, rest = n % 7); + joins str only with str; int(), str(), len() change the type BEFORE the next operator sees it.

W2

Conditionals

0/2 learned · 12 marks
Comparisons
== != < <= > >= give bool · chained a < b < c = (a < b) and (b < c) · bool is an int: True + True = 2
Branch tracing
Substitute inputs, follow ONE branch. A name assigned only inside an if raises NameError when no guarding condition held
× W2-A1 Chained comparison and bool-as-type results
6 marks2 Q

The question asks for the TYPE or value of a comparison expression. a < b < c means (a < b) and (b < c); any comparison gives bool, and bool is an int (True == 1, True + True == 2). Evaluate each link, then combine; the result is bool unless an arithmetic operator is applied afterwards.

× W2-A2 Single if/else trace and unassigned-variable trap
6 marks2 Q

One or two ifs with assignments inside. Substitute the inputs, follow ONE branch, print. If a name is assigned only inside an if and then used outside, it raises NameError exactly when every guarding condition is False.

W3

Conditionals (continued)

0/5 learned · 95 marks
Precedence
not then and then or · reduce innermost brackets first · not not x = x
elif vs if
elif chain: FIRST true branch runs, the rest are skipped · separate ifs are each tested, several (or none) can fire · test boundary values (=, ±1)
Truthiness
Falsy: 0, 0.0, '', [], None · a or b = first truthy · a and b = first falsy · isinstance(True, int) is True
× W3-A2 if / elif / else tracing and input-set questions
38 marks16 Q

Given inputs (or asked for which inputs), walk the chain top to bottom: the FIRST true condition runs and the rest are skipped. For "which inputs give output X", write the interval each branch owns (earlier conditions carve out later ones) and test boundary values (=, +-1) explicitly. For a count of inputs, count integers in the rectangle/interval, inclusive of ends.

× W3-A5 Truthiness, isinstance and short-circuit
17 marks5 Q

Conditions on non-boolean values. Falsy: 0, 0.0, "", empty collections, None; everything else truthy. a or b returns the first truthy operand, a and b the first falsy one (not necessarily a bool). isinstance(True, int) is True. Trace the counter line by line.

× W3-A4 Separate ifs vs elif: equivalence and possible outputs
16 marks5 Q

Compare two blocks or list the possible outputs. Separate ifs are tested independently (several can fire, or none); elif/else makes the branches mutually exclusive. Look for inputs that satisfy two conditions at once — that is where the two versions differ.

× W3-A3 Choose the snippet that is actually correct
13 marks4 Q

Four or five candidate programs for one spec (min of three, age/marks bands, abs value). Test each with the boundary and tie inputs (equal values, exactly on a threshold, negative). The common bugs: independent ifs that print twice, an elif chain with the wrong order, > where >= is needed, a missing else.

× W3-A1 Boolean expression evaluation: not before and before or
11 marks9 Q

Printed boolean expressions mixing not/and/or. Precedence is not, then and, then or; parenthesise mentally, substitute True/False, reduce innermost first. For "deduce the variable" questions, undo not by not: not not x is x.

W4

Iterations and ranges

0/4 learned · 62 marks
range
range(a, b, step): stop is exclusive · range(1, 11) has 10 values · range(n) = 0..n-1
while template
init → test → body → update · trace one row per pass · exit value is the first value that fails the test
Digits
d = n % 10 peels the last digit, n = n // 10 drops it · reverse: r = r*10 + d · start sum at 0, product at 1
× W4-A1 Digit extraction loop (% 10 and // 10)
31 marks9 Q

While n > 0: d = n % 10 peels the last digit, n = n // 10 drops it. Whatever sits between those two lines (sum, product, reverse via r = r*10 + d, position weights, odd-digit filter) is the only part that changes. Start the accumulator at the identity (0 for sum, 1 for product) — a wrong start is the standard trap.

× W4-A2 Pick the loop that prints or accumulates a series
15 marks4 Q

Match the loop bounds to the count: range(1, 11) gives 10 values (stop is exclusive), "first hundred powers" means 100 iterations with the multiplier updated every pass. Check the first value, the last value and the number of iterations of each option.

× W4-A3 While-loop tracing: final value and iteration count
12 marks4 Q

Make a table: one row per iteration with every variable. Stop when the condition first fails and report the value requested (loop variable after exit, count of passes, last term). The exit value is the first value that violates the condition.

× W4-A4 Two-pointer while loop
4 marks2 Q

i starts at the left end, j at the right end; compare the pair sum with the target and move the pointer that can fix it (sum too big -> j -= 1, too small -> i += 1). Trace both pointers per iteration; None/False is returned when they cross.

Data types & scales

2/3 learned · 21 marks
Scales
Nominal labels, no order · Ordinal ranked, gaps unequal · Interval equal gaps, NO true zero (ratios meaningless, 40°C ≠ 2×20°C) · Ratio equal gaps AND true zero (ratios valid)
Descriptive vs inferential
Summarises data collected → descriptive. Uses a sample to generalise to a population → inferential. Trigger words: generalise, population, sampling error, test a claim
✓ W1-A1 Scale-of-measurement property checklist
9 marks4 Q

For any statement about a scale type, run the checklist: nominal = labels/categories only (no order); ordinal = ranked but gaps unequal/unmeasurable; interval = equal gaps but NO true zero, so ratios are meaningless (e.g. 40°C is not 'twice' 20°C); ratio = equal gaps AND a true zero, so ratios ARE meaningful (e.g. income, weight, age) — the presence/absence of a genuine zero point is what separates interval from ratio.

✓ W1-A3 Cross-sectional vs time-series vs data-type classification
8 marks4 Q

First classify the collection structure: same variable(s) tracked over multiple time periods = time-series; different units/subjects observed at a single point in time = cross-sectional. Then classify each variable separately as qualitative (categorical, e.g. nominal/ordinal labels) or quantitative (numeric), and as structured (tabular/numeric) or unstructured (text, images, free-form) when that distinction is tested.

× W1-A2 Descriptive vs inferential statistics scope
4 marks2 Q

Ask of each statement: does it merely summarize/organize the data actually collected (mean, chart, table -> descriptive), or does it use a sample to draw a conclusion, estimate, or generalization about a larger population, typically invoking probability or hypothesis testing (-> inferential)? Statements that mention 'generalizing', 'population', 'sampling error', or 'testing a claim' are inferential; statements that just 'present' or 'summarize' data are descriptive.

Central tendency & dispersion

3/4 learned · 41 marks
Mean
x̄ = Σx / n, so Σx = n·x̄ (use to back out a missing value)
Combined mean
x̄ = (n₁x̄₁ + n₂x̄₂)/(n₁+n₂) — weight by size, never average the averages

Linear transform y = ax+b
mean → a·mean+b · median → a·median+b · percentile → a·p+b · Var → a²·Var · SD → |a|·SD · IQR → |a|·IQR. Location takes b, spread ignores b.
✓ W3-A4 Effect of a linear transform (y = a*x + b) on mean, median, percentile, variance, IQR

W8

Conditional & Bayes

2/5 learned · 42 marks
Conditional
P(A|B) = P(A∩B)/P(B) — restrict to the B row/column and renormalise by that total
Total probability / Bayes
P(B) = Σ P(B|Aᵢ)P(Aᵢ) · P(Aⱼ|B) = P(B|Aⱼ)P(Aⱼ) / P(B)
Independence
P(A∩B) = P(A)P(B) · P(at least one) = 1 − Π(1−Pᵢ) · P(exactly one of A,B) = P(A)(1−P(B)) + (1−P(A))P(B). Never subtract an overlap — independent is not disjoint.
Hypergeometric
P = [KCk · (N−K)C(n−k)] / NCn; sequential draws multiply conditionals with a shrinking denominator
✓ W8-A4 Law of total probability and Bayes' theorem over a partition
18 marks6 Q

Identify the partition of the sample space (boxes, coins, bags, student groups) with known prior probabilities and known conditional probabilities of the event within each branch; compute P(event) = sum of P(event|partition_i)*P(partition_i) via a probability tree, and for a posterior question ('given the event happened, probability it came from partition_i') divide P(event|partition_i)*P(partition_i) by that same total -- the total-probability sum IS the Bayes denominator.

✓ W8-A5 Without-replacement draws: joint/conditional probability and independence (hypergeometric)
7 marks2 Q

When items are drawn sequentially without replacement, multiply successive conditional probabilities while updating the counts after each draw (or use the hypergeometric formula C(k,x)*C(N-k,n-x)/C(N,n) for an exact count); to test independence, compute P(A cap B) this way and compare it to P(A)*P(B) -- without replacement they are almost never equal.

× W8-A2 Conditional probability from a two-way contingency table
6 marks2 Q

When data is laid out as a two-way frequency/contingency table, restrict attention to the row or column matching the given condition, then divide the count (or probability) in the target cell by the row/column total -- read the answer straight off the table instead of building a probability tree.

× W8-A3 Independent events: complement and at-least-one/exactly-one rules
6 marks2 Q

Recognize independence lets you multiply marginal probabilities directly: use P(at least one occurs) = 1 - product of (1 - P(i)) for independent successes, and for 'exactly one happens / they contradict' outcomes sum P(A)(1-P(B)) + (1-P(A))P(B) -- never subtract an overlap term since events are independent, not disjoint.

× W8-A1 Conditional probability directly from a PMF
5 marks2 Q

When given P(X=x) values or a PMF, compute P(A|B) = P(A cap B)/P(B) by summing PMF values that satisfy both conditions and dividing by the sum of PMF values satisfying the given condition -- no Bayes formula needed, just the definition applied to the distribution.

Expectation
E(X) = Σ x·p(x) · E(g(X)) = Σ g(x)·p(x) · E(aX+b) = aE(X)+b · E(X+Y) = E(X)+E(Y) always

5/10 learned · 71 marks
Binomial
P(X=k) = nCk·pᵏ·(1−p)ⁿ⁻ᵏ · E = np · Var = np(1−p). 'At most k' → sum 0…k. 'At least k' → 1 − P(X ≤ k−1).

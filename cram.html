W1

Data types & scales

0/3 learned · 21 marks
Scales
Nominal labels, no order · Ordinal ranked, gaps unequal · Interval equal gaps, NO true zero (ratios meaningless, 40°C ≠ 2×20°C) · Ratio equal gaps AND true zero (ratios valid)
Descriptive vs inferential
Summarises data collected → descriptive. Uses a sample to generalise to a population → inferential. Trigger words: generalise, population, sampling error, test a claim
The four scales, in one pass
  • Nominal — labels only, no order. Gender, blood group, jersey number.
  • Ordinal — ordered labels, gaps unequal or undefined. poor/good/excellent, S/M/L.
  • Interval — equal gaps, differences meaningful, no true zero → ratios meaningless. °C, °F.
  • Ratio — equal gaps and a true zero → ratios valid. Height, weight, marks, runs, income.
Categorical data can only be nominal or ordinal. Numerical data can only be interval or ratio.
Data and variables
Statistics is the art of learning from data: collect → describe → analyse → conclude. Data does not speak by itself — comments, likes and multimedia are all data. Structured = organised rows and columns; unstructured = scattered, no fixed shape.
Tidy data
One variable per column, one case per row, one consistent unit down a column. A column that is constant across every case is not a variable. Never mix cm and feet in one column.
NA is not zero
A bowler who never bowled → NA. A bowler who bowled and took no wickets → 0. Conflating them changes the mean and the count.
Categorical vs numerical, discrete vs continuous
Categorical = group membership. Numerical = has measurement units. Numeric-looking but categorical: jersey number, mobile number, pin code, patient ID — arithmetic on them is meaningless. Within numerical: discrete = whole-number counts, continuous = any fractional value.
Cross-sectional vs time series
Time series = the same variable tracked over successive time points (plot it as a timeplot). Cross-sectional = many units observed at one point in time.
Descriptive vs inferential
Descriptive summarises the data you actually collected. Inferential uses a sample to make a claim about a larger population, and needs probability. Trigger words for inferential: generalise, population, sampling error, test a claim, estimate.

Traps that cost marks

  1. A sample does not make it inferential. Analysing the sample and stopping there is descriptive. It is inferential only when the claim reaches beyond the sample.
  2. Interval vs ratio turns on one question: does zero mean true absence, so that ratios mean something? 40°C is not twice 20°C → interval. 300 runs is twice 150 → ratio.
  3. Mode works on nominal, median does not. Median needs order; nominal has none. The nominal/ordinal swap is the most repeated wrong option across every paper.
  4. Mean is never valid for categorical data. Mode for any categorical, median for ordinal only. “Mean, median and mode can all summarise a categorical variable” is a recurring false MSQ option.
  5. Numeric-looking identifiers are categorical. Jersey number, pin code, room number — the average of them is meaningless.

Practice — solve before you read the answer

Q1A hospital records, for each patient: patient ID, blood group, pain level (mild / moderate / severe), body temperature in °C, and weight in kg. Give the scale of measurement for each, and say which are categorical.

Show answer
patient ID — nominal, categorical (numeric-looking, but arithmetic on it is meaningless).
blood group — nominal, categorical.
pain level — ordinal, categorical (ordered, but the gap from mild to moderate is not a measured quantity).
body temperature °C — interval, numerical. No true zero, so 40° is not twice 20°.
weight kg — ratio, numerical. True zero, so 60 kg really is twice 30 kg.
Only mode can summarise ID and blood group; pain level also admits a median.

Q2A researcher surveys 500 of a college's 4000 students and reports that 62% of those surveyed own a laptop. She then writes: “about 62% of students at this college own a laptop.” Which statement is descriptive and which is inferential, and why?

Show answer
Descriptive: “62% of those surveyed own a laptop” — it only summarises the 500 actually measured.
Inferential: “about 62% of students at this college” — it generalises from the 500 to all 4000, which needs probability and carries sampling error.
The giveaway is not that a sample was used — both sentences use the same sample. It is whether the claim leaves the sample.
× W1-A1 Scale-of-measurement property checklist
9 marks4 Q

For any statement about a scale type, run the checklist: nominal = labels/categories only (no order); ordinal = ranked but gaps unequal/unmeasurable; interval = equal gaps but NO true zero, so ratios are meaningless (e.g. 40°C is not 'twice' 20°C); ratio = equal gaps AND a true zero, so ratios ARE meaningful (e.g. income, weight, age) — the presence/absence of a genuine zero point is what separates interval from ratio.

× W1-A3 Cross-sectional vs time-series vs data-type classification
8 marks4 Q

First classify the collection structure: same variable(s) tracked over multiple time periods = time-series; different units/subjects observed at a single point in time = cross-sectional. Then classify each variable separately as qualitative (categorical, e.g. nominal/ordinal labels) or quantitative (numeric), and as structured (tabular/numeric) or unstructured (text, images, free-form) when that distinction is tested.

× W1-A2 Descriptive vs inferential statistics scope
4 marks2 Q

Ask of each statement: does it merely summarize/organize the data actually collected (mean, chart, table -> descriptive), or does it use a sample to draw a conclusion, estimate, or generalization about a larger population, typically invoking probability or hypothesis testing (-> inferential)? Statements that mention 'generalizing', 'population', 'sampling error', or 'testing a claim' are inferential; statements that just 'present' or 'summarize' data are descriptive.

W2

Charts & frequency

0/4 learned · 11 marks
Pie chart
amount = (percent/100) × total
Relative frequency
rel freq = class freq / Σ freq
Frequency and relative frequency
Frequency = count per distinct category. Relative frequency = frequency ÷ n, and always sums to 1. Use relative frequency whenever you compare two datasets of different sizes.
Which chart does what
  • Pie — share of a whole. Wedge angle = relative frequency × 360°. No 3D, no exploded slices.
  • Bar — comparison across groups. Equal widths, bars do not touch.
  • Pareto — a bar chart sorted by descending frequency. Valid for nominal only.
Area principle
The area drawn must be proportional to the number it represents. Two standard violations: decorative icons scaled on both dimensions at once, and a truncated axis whose baseline is not zero, which exaggerates differences. If you must truncate, mark the axis break explicitly.
Round-off
Percentages rounded one at a time need not total exactly 100%, and pie angles need not total exactly 360°. Check the total.
Centre for categorical data
Mode = the highest-frequency category; defined for nominal and ordinal, and may be bimodal or multimodal. Median = the middle value once ranked; needs order, so ordinal only. Mode and median need not coincide.
Presentation
Collapse many tiny categories into an explicit “Other” bucket rather than silently dropping them. Always label axes, title and legend.

Traps that cost marks

  1. Pareto on ordinal data is wrong. Sorting S/M/L/XL by frequency destroys the order that makes the variable ordinal. Keep the natural order.
  2. A truncated baseline is an area-principle violation, not a style preference. It is the answer to “what is misleading about this chart?”
  3. Median is undefined for nominal data. Mode is the only centre a nominal variable has.
  4. Bars touch in a histogram, not in a bar chart. Gaps mean categories; touching means a continuous axis.
  5. Individually rounded percentages need not sum to 100. If an option says they must, it is false.

Practice — solve before you read the answer

Q1In a survey of 240 people, 54 chose tea as their preferred drink. Give the relative frequency of tea and the angle of its wedge in a pie chart.

Show answer
Relative frequency = 54 / 240 = 0.225 (22.5%).
Angle = 0.225 × 360° = 81°.
Carry the fraction, not the rounded percentage — rounding to 23% first gives 82.8°, outside a tight tolerance band.

Q2Shirt sizes sold: S 12, M 30, L 25, XL 8. (a) Is a Pareto chart appropriate? (b) What is the mode? (c) What is the median size?

Show answer
(a) No. Size is ordinal, and a Pareto chart sorts bars by descending frequency, which would print M, L, S, XL and destroy the natural order. Pareto is for nominal data; here keep S, M, L, XL.
(b) Mode = M (30, the highest frequency).
(c) n = 75, so the median is the 38th value in size order. Cumulative counts: S 12, M 42 — the 38th falls inside M, so median = M. A median exists here precisely because the variable is ordinal; for a nominal variable this part would have no answer.
× W2-A2 Convert pie chart percentages to actual amounts
5 marks2 Q

Multiply each category's stated percentage by the known total (or back out the total from one category's percent-and-value pair), then add or subtract the resulting amounts as the question asks.

× W2-A1 True/false statements on categorical variable properties
2 marks1 Q

Classify the variable as nominal or ordinal, then recall that mode is a valid summary for categorical data while covariance/correlation require numeric (interval/ratio) variables — check each statement against these definitions rather than computing anything.

× W2-A3 Evaluate statements from a pie chart of percentages
2 marks1 Q

Work directly with the percentage shares shown (no total needed) — rank categories by their percent slice or sum two slices to check a claimed comparison, then judge each statement true/false.

× W2-A4 Compute relative frequency from a bar chart
2 marks1 Q

Read off the bar height (frequency) for the category asked about, sum all bar heights to get the total, and divide: relative frequency = category frequency / total frequency.

W3

Central tendency & dispersion

0/4 learned · 41 marks
Mean
x̄ = Σx / n, so Σx = n·x̄ (use to back out a missing value)
Combined mean
x̄ = (n₁x̄₁ + n₂x̄₂)/(n₁+n₂) — weight by size, never average the averages
Quartiles / IQR
order data, locate Q₁ Q₃ by position, IQR = Q₃ − Q₁
Linear transform y = ax+b
mean → a·mean+b · median → a·median+b · percentile → a·p+b · Var → a²·Var · SD → |a|·SD · IQR → |a|·IQR. Location takes b, spread ignores b.
Tables and plots
Discrete with few distinct values → one class per value. Continuous → grouped classes, 5–20 as a rule of thumb. Convention: a class includes its left end and excludes its right, so “30–40” contains 30 but not 40. Histogram bars touch (continuous axis). Stem-and-leaf keeps the actual values: stem = all digits but the last, leaf = the last digit, leaves sorted within a row.
Mean
Sample x̄ = Σx / n, population μ = Σx / N. Grouped discrete: Σf·x / n, which is exact. Grouped continuous: Σf·midpoint / n, which is an approximation. Highly sensitive to outliers.
Median and mode
Sort first. n odd → the ((n+1)/2)-th value. n even → the average of the two middle values. Median is not sensitive to outliers. Mode may not exist and may be multiple.
Transformations — learn this cold
  • y = x + c → mean, median and mode all shift by c. Variance and SD unchanged.
  • y = c·x → mean, median and mode scale by c. Variance scales by c², SD scales by c (not c²).
Combined y = c·x + d: centre scales then shifts; spread only scales.
Spread
Range = Max − Min, uses two points, extremely outlier-sensitive. Sample variance s² = Σ(x − x̄)² / (n − 1). Population variance σ² = Σ(x − μ)² / N. SD = √variance, which restores the original units. Why it matters: {3,3,3,3,3} and {1,2,3,4,5} share a mean, median and mode but differ entirely in spread.
Percentiles — two valid algorithms
Manual: sort, compute n·p. Not an integer → round up and take that rank. An integer → average that rank and the next.
Spreadsheet PERCENTILE(): rank = p(n − 1) + 1, then interpolate between the whole and fractional parts.
They disagree, so read which one the question wants.
Quartiles
Q1 = 25th percentile, Q2 = median, Q3 = 75th. Five-number summary: Min, Q1, Q2, Q3, Max. IQR = Q3 − Q1, more robust than range or SD. Outlier fences: Q1 − 1.5·IQR and Q3 + 1.5·IQR.

Traps that cost marks

  1. n − 1 for a sample, n for a population. This is the single most common silent error in the whole course — it never announces itself, the number just comes out wrong.
  2. Adding a constant does not change spread. y = x + c leaves variance and SD exactly as they were.
  3. Scaling hits variance by c² but SD only by c. Squaring the SD change is the planted wrong option.
  4. Percentile rule: n·p integer → average that rank and the next; not an integer → round up. Rounding to nearest is wrong.
  5. Mean moves with an outlier, median does not. “Which measure is resistant?” is always asking this.
  6. Grouped continuous mean is an approximation, because midpoints replace the real values. Grouped discrete is exact.

Practice — solve before you read the answer

Q1For the sample 4, 8, 6, 10, 12, compute the mean, the sample variance and SD, and the population variance and SD. Say which pair the exam means by default when it says “this sample”.

Show answer
Mean = (4+8+6+10+12)/5 = 40/5 = 8.
Deviations: −4, 0, −2, 2, 4 → squares 16, 0, 4, 4, 16 → Σ = 40.
Sample: s² = 40 / (5 − 1) = 10, s = √10 ≈ 3.16.
Population: σ² = 40 / 5 = 8, σ = √8 ≈ 2.83.
The word sample means divide by n − 1. The two answers differ by 25% here — far wider than any tolerance band.

Q2A dataset has mean 50 and SD 6. Every value is transformed by y = 3x − 10. Give the new mean, variance and SD.

Show answer
Mean = 3(50) − 10 = 140 — scales, then shifts.
SD = |3| × 6 = 18 — scales by c, and the −10 does nothing.
Variance = 3² × 6² = 9 × 36 = 324 (= 18²).
The two planted wrong answers: scaling the SD by c² (giving 54), and shifting the spread by −10.
× W3-A4 Effect of a linear transform (y = a*x + b) on mean, median, percentile, variance, IQR
18 marks6 Q

For y = a*x + b: mean_y = a*mean_x + b and var_y = a^2*var_x; any single-point location statistic (median, a percentile) transforms the same way as the mean (multiply by a, add b); spread measures based on differences of two points (like IQR) are unaffected by a pure shift (b) and scale by |a| under a scale change.

× W3-A2 Combined/weighted mean of merged subgroups
10 marks3 Q

Use Sum(x) = n * mean for the whole group and for each subgroup; since the whole group's total sum equals the sum of subgroup totals, solve the resulting linear equation for the missing subgroup total or single observation.

× W3-A3 Solve for unknown(s) from a given mean, then derive another statistic
10 marks3 Q

Set up Sum(x) = n * mean as an equation in the unknown(s) (an unknown data value, a misrecorded entry, or an unknown variance term), solve algebraically, then plug back to compute the requested derived quantity (corrected mean, median, or |difference of unknowns|).

× W3-A1 IQR via ordered data and quartile position formula
3 marks1 Q

Sort the data, locate Q1 and Q3 using the quartile position formula (e.g. (n+1)/4 and 3(n+1)/4), then IQR = Q3 - Q1.

W4

Correlation

0/3 learned · 17 marks
Pearson r
r = [nΣxy − ΣxΣy] / √([nΣx² − (Σx)²][nΣy² − (Σy)²]) — build the 5 columns x, y, xy, x², y²
Invariance
r unchanged by positive linear transforms; a negative multiplier flips the sign only
Contingency table
row totals, column totals, grand total — then decide if the question wants joint, marginal or conditional
Association is not causality
The course only ever claims association. Any option asserting cause from a correlation or a contingency table is false.
Contingency tables
Rows and columns are category levels, cells are counts, margins are row and column totals. Keep the natural order for ordinal variables — do not let alphabetising reorder S/M/L. Row (or column) relative frequency = cell ÷ its row (or column) total.
The association rule, in one line
If the row relative frequencies are roughly the same across all rows → no association. If they differ noticeably → associated. Checking by column gives the same verdict.
Bar charts for two variables
Stacked shows raw counts. 100% stacked normalises each bar to the same height, which is what you want for comparing shares across groups of different sizes.
Scatter plots
x = explanatory, y = response. Describe with D-C-V-O: Direction, Curvature, Variation, Outliers. The course only quantifies linear association.
Covariance and correlation
Cov(x,y) = Σ(x − x̄)(y − ȳ) / (n − 1) for a sample, / N for a population. The sign gives direction; the magnitude is hard to read because the units are mixed.
r = Cov(x,y) / (sx·sy) — unitless, always in [−1, +1]. |r| near 1 is strong linear association, near 0 is weak. Swapping which variable is on which axis does not change r.
Line of best fit and R²
y = mx + c. The sign of m gives the direction. R² = r² is the proportion of variance explained — it measures fit strength and carries no direction.
Point bi-serial
For one numerical x against one dichotomous categorical y coded 0/1: rpb = (Ȳ0 − Ȳ1) / sx × √(p0p1), using group means and group proportions. Line fitting does not apply, because x takes only two values.

Traps that cost marks

  1. Association never licenses a causal claim, however strong r is.
  2. y = x + c has r = 1 exactly (and y = −x + c has r = −1). Recognise the shape instead of recomputing.
  3. R² has no direction. R² = 0.64 is consistent with r = +0.8 and with r = −0.8 alike.
  4. The sign of rpb flips if you swap which category is coded 0 and which 1. Only |rpb| means anything.
  5. Point bi-serial needs exactly one numeric and one binary variable. Two categorical variables, or a three-level category, do not qualify.
  6. Correlation is unitless and axis-independent. Changing units or swapping axes leaves r alone.

Practice — solve before you read the answer

Q1A sample gives Cov(x, y) = 12.6, sx = 4.2 and sy = 5.0. Find r and R², and state what each one tells you.

Show answer
r = 12.6 / (4.2 × 5.0) = 12.6 / 21 = 0.6.
R² = 0.6² = 0.36.
r = 0.6 — a moderate positive linear association; as x rises, y tends to rise.
R² = 0.36 — 36% of the variation in y is explained by the linear fit. It says nothing about direction; an r of −0.6 would give the same 0.36.

Q2Of students who attended the revision session, 60 passed and 20 failed. Of those who did not attend, 15 passed and 45 failed. Is attendance associated with passing? Can you conclude the session caused the passes?

Show answer
Row totals: attended 80, did not attend 60.
Row relative frequencies for passed: attended 60/80 = 0.75; did not attend 15/60 = 0.25.
The two rows differ sharply, so the variables are associated.
No causal conclusion. Students who choose to attend a revision session are likely to be the ones already studying harder, so the comparison is confounded. The course claims association only.
× W4-A1 Compute Pearson r from raw paired data
11 marks3 Q

Given paired (x,y) observations, compute r = [nΣxy - ΣxΣy] / sqrt([nΣx²-(Σx)²][nΣy²-(Σy)²]) (or use deviations from means) and read the sign/magnitude to judge strength and direction of the linear relationship.

× W4-A2 Correlation invariance under linear transformation
3 marks1 Q

If X and Y are each replaced by linear transforms a+bX and c+dY, correlation is unchanged in magnitude and its sign flips only if exactly one of b,d is negative — no recomputation needed, just track sign(b)*sign(d).

× W4-A3 Read and reason from a contingency table
3 marks2 Q

Locate the row/column intersection for the stated categories, use row/column/grand totals to back out any unknown cell via subtraction, then form the requested proportion (part/relevant total).

W1

Intro to algorithms

0/1 learned · 17 marks
Operators
/ always gives float · // floors · % remainder (days = n // 7, rest = n % 7) · ** power · int op float → float
Types
int float str bool · a quoted number is str · int('5')+1 = 6, '5'+1 is a TypeError · str + str joins, str * int repeats
Output formats
len(s) counts characters · f-string width f'{x:5}' right-aligns numbers in 5 columns · print(a, b) puts a space between
Type rules — the whole of W1
  • int op int → int, except / (always float) and ** with a negative exponent (2**-3 → 0.125, a float).
  • int op float → float. One float anywhere poisons the whole expression: 7.0 // 2 → 3.0, not 3.
  • A quoted literal is str even when it looks numeric: "7" + "2" → "72", not 9.
  • + joins str with str only. "a" + 1 → TypeError. But "ab" * 3 → "ababab" is legal.
  • int(), str(), float(), len() change the type before the next operator sees it — that is usually the point of the question.
Floor division and modulo
// floors, % keeps the remainder. The standard decomposition: years = n // 365, weeks = (n % 365) // 7, days = (n % 365) % 7.
⚠ // floors toward −∞, it does not truncate: -7 // 2 is −4, not −3. And % takes the sign of the divisor: -7 % 2 is 1, not −1.
Strings
s[a:b] includes a and excludes b, so the length is b − a, clipped at the ends. s[:k] is the first k characters. len(s) counts characters — spaces you concatenated in are characters too.
f-string widths
f"{5:3}" pads to 3 columns and right-aligns numbers → "  5". The padding counts toward the output length.
Method
Every W1 question is one expression. Work inside-out: evaluate the innermost call, note its type, then apply the next operator to that.

Traps that cost marks

  1. / always returns a float, even 4/2 → 2.0. If the options show 2 and 2.0, that is the whole question.
  2. -7 // 2 is −4, because floor division rounds down, not toward zero.
  3. -7 % 2 is 1, because the result takes the sign of the divisor.
  4. One float poisons the expression. 7.0 // 2 → 3.0, and the answer 3 is marked wrong.
  5. Quoted numbers are strings. "5" + 1 is a TypeError; int("5") + 1 is 6.
  6. Field width adds characters. f"{7:4}" is four characters long, three of them spaces.

Practice — solve before you read the answer

W2

Conditionals

0/2 learned · 12 marks
Comparisons
== != < <= > >= give bool · chained a < b < c = (a < b) and (b < c) · bool is an int: True + True = 2
Branch tracing
Substitute inputs, follow ONE branch. A name assigned only inside an if raises NameError when no guarding condition held
Comparisons give bool
== != < <= > >= all produce a bool.
Chained comparison
a < b < c means (a < b) and (b < c), and b is evaluated only once. The result is a bool.
bool is an int
True == 1, False == 0, True + True == 2. So type(1 < 2) is bool, but (1 < 2) + 1 is 2, an int. A comparison stays a bool until an arithmetic operator is applied to it.
Tracing a single if/else
Substitute the inputs, follow exactly one branch, print. Write the variable values in the margin — not in your head.
The unassigned-variable trap
If a name is assigned only inside an if body and then used after the block, the code raises NameError precisely for the inputs that satisfy none of the conditions. The question is almost always “for which inputs does this error?”
Precision: at module level that is a NameError. Inside a function it surfaces as UnboundLocalError, which is a subclass of NameError — if both appear as options, the function case wants UnboundLocalError.

Traps that cost marks

  1. True + True is 2, not True. Arithmetic on bools gives ints.
  2. a < b < c is not (a < b) < c. It expands to an and, and b is evaluated once.
  3. The NameError fires when every condition is False — find the inputs that no branch covers, and that set is the answer.
  4. An if with no else can produce no output at all. “Nothing is printed” is a real option, not a trick.
  5. = is assignment, == is comparison. A planted = inside a condition is a SyntaxError, not a silent bug.

Practice — solve before you read the answer

Q1What does this print, and for which values of x would it instead raise an error?

x = 3
if x > 10:
    y = "big"
elif x > 5:
    y = "mid"
print(y)

Show answer
With x = 3 it raises NameError: name 'y' is not defined. Neither condition held, so y was never assigned.
It errors for every x ≤ 5. It prints mid for 5 < x ≤ 10, and big for x > 10.
Note the boundary: x = 5 errors, because 5 > 5 is False. Had the same code sat inside a function, the error would be UnboundLocalError.

Q2Give the value and the type of each expression, with a, b, c = 2, 5, 9:

a < b < c
(a < b) + (b < c)
type(a < b < c)
True + True
(1 < 2) + 1

Show answer
a < b < c → True (bool) — expands to (2<5) and (5<9).
(a < b) + (b < c) → 2 (int) — True + True.
type(a < b < c) → <class 'bool'>.
True + True → 2 (int).
(1 < 2) + 1 → 2 (int) — the comparison is a bool until the + turns it into an int.
× W2-A1 Chained comparison and bool-as-type results
6 marks2 Q

The question asks for the TYPE or value of a comparison expression. a < b < c means (a < b) and (b < c); any comparison gives bool, and bool is an int (True == 1, True + True == 2). Evaluate each link, then combine; the result is bool unless an arithmetic operator is applied afterwards.

6 marks2 Q

One or two ifs with assignments inside. Substitute the inputs, follow ONE branch, print. If a name is assigned only inside an if and then used outside, it raises NameError exactly when every guarding condition is False.

W3

Conditionals (continued)

0/5 learned · 95 marks
Precedence
not then and then or · reduce innermost brackets first · not not x = x
elif vs if
elif chain: FIRST true branch runs, the rest are skipped · separate ifs are each tested, several (or none) can fire · test boundary values (=, ±1)
Truthiness
Falsy: 0, 0.0, '', [], None · a or b = first truthy · a and b = first falsy · isinstance(True, int) is True
Precedence — memorise cold
arithmetic → comparisons → not → and → or (loosest last).
not True and False is (not True) and False = False.
True or False and False is True or (False and False) = True.
Parenthesise on paper before substituting, then reduce innermost first. To undo a double negative: not not x is x.
elif chains vs separate ifs — the half of the paper
In an if/elif/else chain the first true condition runs and every later one is skipped. Separate ifs are each tested independently, so several can fire, or none — output can print twice.
To find where two versions differ, look for an input that satisfies two conditions at once. That input is the answer.
Intervals that branches actually own
Earlier conditions carve out later ones. if x > 10 then elif x > 5 means branch two owns 5 < x ≤ 10, not x > 5. Write each branch's real interval down, then test the threshold itself and ±1.
Counting integers in an inclusive interval a ≤ x ≤ b: b − a + 1 values.
Truthiness
Falsy is exactly: 0, 0.0, "", [], {}, (), None. Everything else is truthy — including "0", " ", "False", -1 and [0].
Short-circuit returns the operand, not a bool
a or b → the first truthy operand, or the last one if all are falsy. 0 or "x" is "x"; 3 or 5 is 3.
a and b → the first falsy operand, or the last one if all are truthy. "" and 5 is ""; 3 and 5 is 5.
isinstance
isinstance(True, int) is True (bool subclasses int), but isinstance(1, bool) is False. That asymmetry is the entire content of the two hardest questions in the pool.
Two things that look like operators you know
& and | are bitwise, not logical: 5 & 3 is 1. On two bools they behave logically and return a bool, but they do not short-circuit and they bind tighter than you expect. If you see them, slow down.
return inside an if exits the function immediately — nothing after it runs, including later elifs.
“Choose the correct snippet”
Do not read for elegance. Test each candidate on the nasty inputs: equal values (ties), exactly the threshold, and a negative. The planted bug is always one of four: independent ifs printing twice, an elif chain in the wrong order, > where >= was needed, or a missing else.

Traps that cost marks

  1. Precedence is not → and → or. not True and False is False, and True or False and False is True.
  2. First true branch wins in an elif chain; separate ifs are all tested. The favourite MSQ is an input satisfying two conditions, because that is the only place the versions differ.
  3. Earlier conditions carve out later ones. Branch two of >10 / >5 owns 5 < x ≤ 10. Always test the threshold and ±1.
  4. "0", " ", "False", -1 and [0] are all truthy. Only the seven falsy values are falsy.
  5. or and and return an operand, not a bool. 0 or "x" is "x", not True.
  6. isinstance(True, int) is True but isinstance(1, bool) is False. The asymmetry is the question.

W4

Iterations and ranges

0/4 learned · 62 marks
range
range(a, b, step): stop is exclusive · range(1, 11) has 10 values · range(n) = 0..n-1
while template
init → test → body → update · trace one row per pass · exit value is the first value that fails the test
Digits
d = n % 10 peels the last digit, n = n // 10 drops it · reverse: r = r*10 + d · start sum at 0, product at 1
range
range(start, stop, step) excludes stop. range(1, 11) yields 10 values, 1 through 10. range(10, 0, -2) yields 10, 8, 6, 4, 2. Number of values = ceil((stop − start) / step).
Checking a candidate loop
“First hundred powers of two” means 100 iterations with the multiplier updated every pass. Check exactly three things on every candidate: the first value printed, the last value printed, and the number of iterations. One distractor is always off by one at exactly one of those three.
The digit-extraction skeleton — nine questions ride on this
while n > 0:
    d = n % 10        # peel the last digit
    # <<< the only line that changes >>>
    n = n // 10       # drop it
What sits in the middle is a sum (s += d), a product (p *= d), a reversal (r = r*10 + d), a positional weight (t += d*w; w *= 10), or a filter (if d % 2: s += d).
Accumulator identity
Start a sum at 0 and a product at 1. A product started at 0 returns 0 for every input — that is the standard planted bug. while n > 0 on input 0 runs the body zero times, so you get the initial accumulator straight back. Digit loops also assume a positive n: on a negative input the body never runs.
Tracing — do not do it in your head
Make a table: one row per iteration, one column per variable, plus a column for the condition's truth value. Stop when it first fails.
“Final value of the loop variable” = the first value that violates the condition, not the last one that satisfied it.
“Iteration count” = the number of rows in your table. Count them, do not estimate.
Two-pointer loop
i starts at the left end, j at the right, and you compare a[i] + a[j] with the target. Sum too big → j -= 1. Too small → i += 1. The loop runs while i < j; when the pointers cross, nothing was found and it returns None/False. “For which arguments does it return None?” is asking which input has no valid pair.
Simultaneous assignment
a, b = b, a + b uses the old values of both on the right-hand side. Write both variables on every row of your table or you will get it wrong.

Traps that cost marks

  1. A product accumulator started at 0 returns 0 for every input. Sums start at 0, products start at 1 — this is an exam question twice over.
  2. while n > 0 never runs on input 0, so the printed answer is the initial accumulator value.
  3. range(a, b) excludes b. range(1, 11) is ten values, not eleven.
  4. The final loop variable is the first value that breaks the condition, not the last one that passed it.
  5. a, b = b, a + b uses the old values of both. Updating them one at a time gives a different, wrong sequence.
  6. Off-by-one lives in three places: the first value, the last value, and the iteration count. Check all three on every candidate.

Q1What does this print? Then fix it, and say what the fixed version prints for n = 234 and for n = 0.

n = 234
p = 0
while n > 0:
    d = n % 10
    p *= d
    n = n // 10
print(p)

Show answer
As written it prints 0. The accumulator starts at 0, so the very first p *= d gives 0 and every later multiply keeps it there — the loop runs correctly and the answer is still 0 for every input.
Fix: p = 1. Then n = 234 peels 4, 3, 2 and prints 24.

Q2Give the values printed, the iteration count, and the value of the variable after each loop.

for i in range(10, 0, -3):
    print(i)

# and separately:
j = 1
while j < 20:
    j = j * 3
print(j)

Show answer
for loop: prints 10, 7, 4, 1 — stop is excluded, so it never reaches 0. Count = ceil((0 − 10) / −3) = ceil(3.33) = 4 iterations. After the loop i is 1, the last value yielded.

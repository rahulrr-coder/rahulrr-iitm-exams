Tonight’s Math 2 picks · 66 marks

W6-A330 marksGeneral [T] with respect to two bases B1 → B2

Your second-heaviest Math 2 archetype and completely untouched. It is a procedure, not a theory: apply T to each vector of B1, express each result in B2 coordinates, stack those coordinate vectors as columns. That is the whole method — the only hard part is the B2 coordinate solve, which is one small linear system per column.

W11-A219 marksFind and classify ALL critical points, then tally

You already hold W11-A1, the Hessian test at one given point. This is the same test run over every point you find yourself. Solve f_x = 0, f_y = 0 simultaneously, then D = f_xx·f_yy − (f_xy)²: D>0 & f_xx>0 → min · D>0 & f_xx<0 → max · D<0 → saddle · D=0 → inconclusive. The only new work is the simultaneous solve.
